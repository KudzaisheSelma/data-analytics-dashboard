# Data Analytics Dashboard

An enterprise-grade analytics interface processing complex datasets into digestible, interactive visual reports for executive decision making.

## Tech Stack
- **Frontend**: React, Recharts, Tailwind CSS
- **API**: GraphQL with Apollo Client
- **Backend**: Node.js, Apollo Server
- **Database**: PostgreSQL

## Getting Started
```bash
npm install
cp .env.example .env
npm run dev
```

## Features
- Interactive bar, line, pie, and area charts
- KPI metric cards with trend indicators
- Date range filtering
- Data table with sorting and pagination
- CSV/PDF export
- Real-time data updates
- Responsive layout for all screen sizes
